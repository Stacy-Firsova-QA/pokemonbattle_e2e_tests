# Структура проекта

### Директория *tests*
Основа проекта - здесь хранятся тесты.
e2e - основные e2e тесты
screenshot - скриншот-тесты

### Директория *data*
Тестовые данные для проверок.

### Директория *fixtures*
Здесь лежат фикстуры (ui и api фикстуры)

### Директория *helpers*
Помощники :)

### Директория *locators*
Отдельно вынесены локаторы по отдельным pages

### Директория *pages*
Методы для отдельных страниц по принципу PageObject

### Файл *conftest*
Модуль для фикстур, хуков и пр.

### Файл *pytest.ini*
Файл с пользовательскими pytest.mark

### Файл *.env.example*
Здесь храним секьюрные данные (например, токен).

Не пушим! В удаленном репозитории будет всегда лежать .env.example для ввода своих данных.
